# 多用户平台设计

## 角色

- `student`：学习单词、文章、练习和复习，仅访问自己的学习数据。
- `admin`：拥有学习者能力，并可管理用户、角色、账号状态和教学内容。

## 数据存储

- `users`：用户 ID、用户名、显示名称、角色、状态、bcrypt 密码哈希和登录时间。
- `sessions`：随机会话令牌、用户 ID 和过期时间。Cookie 使用 HttpOnly 与 SameSite=Lax。
- `progress`：学习进度。平台阶段按用户 ID 隔离。
- `articles`：文章正文、翻译、难度、主题、词汇和佳句。
- `words`、`pronunciations`、`examples`：词条及其教学资源。

## 内容导入

管理员后台接受 JSON 文件：

- 文章：数组或 `{ "items": [...] }`。
- 单词：数组或 `{ "items": [...] }`，导入时选择小学或初中。

服务端会再次校验角色，隐藏管理页面不能代替权限控制。

## 初始管理员

- 用户名：`admin`
- 初始密码：`Admin123!`

首次登录后应尽快创建新的管理员账号并修改初始化策略。生产部署还应增加邮件验证、密码重置、登录限流、审计日志、CSRF 防护和数据库备份。
