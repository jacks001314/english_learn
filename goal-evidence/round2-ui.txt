## 4. 变式练习（quickAction=drill，线上真实模型）
itemCount = 3
item1: q=bit           options=[一点儿,小片 / 吃完,吃光 / 充满....的 / 少量(的),一点]  answer=一点儿,小片
item2: q=one(large)bowl of  options=[充满....的 / 一（大）碗 / 少量(的),一点 / 吃完,吃光] answer=一（大）碗
item3: q=be full (of)  options=[少量(的),一点 / 充满....的 / 一（大）碗 / 吃完,吃光] answer=充满....的
→ 每题 4 个选项互不重复，且包含正确答案（修复了此前「感冒」与「感冒;伤风」同时作选项的问题）
focus = 学生把表示“少量、一点”的 a bit (of) 与其他含 of 的数量/状态短语混在一起…
→ focus 引用了学生实际混淆点，证明页面上下文已送达服务端
